# SKYBREAK

A neon rooftop platform roguelite, playable on desktop or mobile. Double-jump, dash, collect shards, and outrun the rising void.

**Play:** https://sirioitalianfactory.github.io/skybreak/

## Controls

- Arrow keys or A/D: Move
- Space or Up: Jump (double jump)
- Shift: Dash
- On mobile: Use the on-screen buttons

## Deployment

Every push to `main` deploys through `.github/workflows/deploy.yml`. In repository **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions** if it is not already configured.
